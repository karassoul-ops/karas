# SUMA — 업무 문서 작성 도우미 (Claude 커넥터)

SUMA는 공공기관과 민간기업 실무자가 매일 쓰는 업무 문서를 Claude와 함께 작성·분석·검토하도록 돕는 스킬입니다. Claude에 **커넥터(MCP)** 로 연결해 두면, 평소처럼 "보고서 써 줘"라고 요청하기만 해도 SUMA가 문서 종류와 보고 대상을 파악해 알맞은 틀과 문체로 초안을 만듭니다.

> 이 페이지는 이용 안내서입니다. SUMA 스킬 원문은 저작권자의 기밀이라 공개하지 않으며, 커넥터로 연결해도 원문은 보이지 않습니다.

## 1. SUMA는 무엇을 하나요

업무 문서는 종류마다 정해진 틀이 있고, 누구에게 보고하느냐에 따라 분량과 말투가 달라집니다. SUMA는 이 판단을 대신 챙겨 줍니다.

| 기능 | 설명 |
|:---|:---|
| 문서 종류 자동 판별 | 요청 문장에서 기안·보고서·계획서·회의록 같은 문서 종류를 알아내고, 그 문서에 맞는 목차와 형식으로 씁니다 |
| 보고 대상 맞춤 | 실무 검토용인지, 실장·본부장·기관장 보고용인지에 따라 분량과 강조점을 조절합니다 |
| 공공·민간 구분 | 공공기관 문서(개조식, 두괄식)와 기업 문서의 관행을 구분해 적용합니다 |
| 수치·사실 점검 | 본문에 들어간 숫자와 사실 관계를 다시 확인하고, 근거가 없으면 비워 두거나 표시합니다 |
| 자연스러운 문장 | 기계적으로 반복되는 표현을 걸러, 사람이 쓴 것처럼 읽히는 문장으로 다듬습니다 |
| 보안 등급 주의 | 대외비·개인정보처럼 AI에 넣으면 안 되는 자료를 알려 주고, 입력 전에 확인을 요청합니다 |

어떤 기능을 쓸지는 SUMA가 요청 내용을 보고 스스로 고릅니다. 이용자가 기능 이름을 외울 필요는 없습니다.

## 2. 이런 일에 씁니다

| 분야 | 문서 예 |
|:---|:---|
| 기안·결재 | 기안문, 품의서, 전결 검토서, 이사회 상정안 |
| 보고 | 주간·월간 보고, 현안 보고, 결과 보고, 상급 기관 제출 자료 |
| 기획 | 사업계획서, 추진계획, 기획안, 제안서 |
| 회의 | 회의록, 회의 자료, 안건 요약 |
| 예산·계약 | 소요 예산 산출, 원가 계산, 수의계약 사유서, 제안요청서(RFP) |
| 정보화 사업 | 발주·감리·검수 관련 문서, 기능점수(FP) 산정, 과업 변경 검토 |
| 감사·법무 | 감사 대응 자료, 법적 검토 의견, 컴플라이언스 점검 |
| 대외 소통 | 보도자료, 공고문, 안내문, 민원 답변, 이메일 |
| 분석 | 설문·데이터 분석 보고서, 교차 분석, 칼럼 |
| 문체 | 초안 다듬기, 문체 변환, 보고서 작성법 코칭 |

## 3. 준비물

- **Claude 계정** — 커스텀 커넥터를 추가할 수 있는 요금제가 필요합니다(예: Pro, Max, Team, Enterprise). 요금제별 지원 범위는 Claude 쪽 정책에 따라 바뀔 수 있습니다.
- **GitHub 계정** — SUMA 로그인에 씁니다. 계정이 없으면 <https://github.com/signup> 에서 무료로 만들 수 있습니다. 비밀번호나 토큰을 SUMA에 따로 등록하지 않습니다.

## 4. 연결하기 (설치)

설치할 프로그램은 없습니다. Claude에 커넥터 주소를 한 번 등록하면 됩니다.

**커넥터 주소**

```
https://fluffy-space-goldfish-jrj69jv5wx7wh5wp4-8000.app.github.dev/mcp
```

> 서버를 옮기면 주소가 바뀔 수 있습니다. 연결이 안 되면 이 페이지에서 최신 주소를 다시 확인해 주세요.

### 4-1. claude.ai (웹) — 권장

한 번 연결하면 Claude 데스크톱 앱과 모바일 앱에도 자동으로 들어갑니다.

1. PC 브라우저로 <https://claude.ai> 에 로그인합니다.
2. 왼쪽 메뉴 **Customize(사용자 정의) → Connectors(커넥터)** 로 들어갑니다.
3. **+ → Add custom connector** 를 누릅니다.
4. 이름에 `SUMA`, URL에 위 커넥터 주소를 붙여 넣습니다. 끝에 `/`를 붙이지 않습니다.
   - 고급 설정의 OAuth Client ID·Secret 칸은 **비워 둡니다**.
5. **Add → Connect** 를 누릅니다.
6. GitHub 경고 화면이 나오면 **Continue** 를 누릅니다.
7. 「SUMA 연결」 화면에서 **GitHub 계정으로 로그인** 을 누르고, GitHub 화면에서 **Authorize** 를 누릅니다.
   - 10분 안에, 같은 브라우저에서 끝내야 합니다.
8. 커넥터 목록에 SUMA가 **Connected** 로 보이면 완료입니다.

### 4-2. Claude Code

터미널에서 한 줄을 실행한 뒤, Claude Code 안에서 `/mcp` → SUMA → **Authenticate** 를 눌러 GitHub로 로그인합니다.

```bash
claude mcp add --transport http -s user suma "https://fluffy-space-goldfish-jrj69jv5wx7wh5wp4-8000.app.github.dev/mcp"
```

## 5. 사용하기

1. Claude 대화창 아래 **+ → Connectors** 에서 **SUMA 스위치를 켭니다.** 끄면 SUMA 없이 일반 Claude로 동작합니다.
2. 평소처럼 요청합니다. 따로 명령어를 입력하거나 파일을 첨부할 필요는 없습니다. 업무 문서 요청이면 SUMA가 자동으로 불려 와 적용됩니다.
3. 참고 자료(기존 보고서, 데이터, 회의 메모)가 있으면 함께 붙여 넣으면 더 정확해집니다.
4. 결과가 마음에 들지 않으면 "실장 보고용으로 한 장 분량으로 줄여 줘"처럼 대상과 분량을 말해 주세요.

**잘 쓰는 요령**

- **누구에게 보고하는지** 적어 주세요. 예: 팀장 검토용, 본부장 보고용, 부처 제출용
- **분량** 을 정해 주세요. 예: 1쪽 요약, 3쪽 이내
- **꼭 들어갈 수치·사실** 은 직접 적어 주세요. SUMA는 근거 없는 숫자를 지어내지 않고 빈칸이나 확인 필요 표시로 남깁니다.

**연결 확인**

대화창에서 `SUMA 버전 알려줘` 를 입력하면 서버의 스킬 버전과 오늘 사용량이 나옵니다.

## 6. 요청 예시

```text
다음 달 시행하는 스마트 민원 안내 서비스의 추진계획서를 써 줘.
대상은 본부장 보고용, 2쪽 이내. 예산은 3천만 원, 기간은 11~12월이야.
```

```text
아래 회의 메모로 회의록을 만들어 줘. 결정 사항과 후속 조치는 표로 정리해 줘.
(메모 붙여 넣기)
```

```text
첨부한 설문 결과를 분석해서 결과 보고서 초안을 써 줘.
연령대별 차이가 핵심이고, 한계점도 한 단락 넣어 줘.
```

```text
이 기안문 초안을 검토해 줘. 형식 오류, 근거가 빠진 부분, 어색한 문장을 짚어 줘.
```

```text
이 보도자료를 딱딱하지 않게 다듬어 줘. 사실관계는 바꾸지 말고.
```

## 7. 보안과 개인정보

- **스킬 원문 비공개** — SUMA 스킬 원문은 서버 안에 암호화돼 있습니다. Claude는 문서를 쓸 때 필요한 부분만 받아 적용하고, 원문을 보여 주거나 내보내 달라는 요청은 거절합니다.
- **로그인 정보** — GitHub 로그인은 이용자의 GitHub 아이디 확인에만 씁니다. 저장소나 코드 등 다른 권한은 요청하지 않습니다.
- **입력 자료 주의** — 대외비, 개인정보, 비공개 계약 정보처럼 외부 AI 서비스에 넣으면 안 되는 자료는 입력하지 마세요. 기관·회사의 AI 활용 지침을 먼저 따라 주세요.
- **접속 경로** — 서버는 GitHub에서만 실행되고, 외부와는 HTTPS로만 통신합니다.

## 8. 이용 시간과 한도

- **운영 시간** — 서버는 한국 시간 **평일 08~20시** 에 자동으로 켜 둡니다. 그 밖의 시간에는 서버가 쉬고 있어 연결이 안 될 수 있습니다.
- **하루 사용량** — 이용자 한 명당 하루 열람량에 한도가 있습니다. 한도에 닿으면 다음 날 다시 쓸 수 있습니다.

## 9. 문제 해결

| 증상 | 확인할 것 |
|:---|:---|
| 연결할 때 「로그인 서비스에 등록할 수 없습니다」 | 서버가 쉬는 시간일 수 있습니다. 평일 08~20시에 다시 **Connect** 를 눌러 주세요 |
| 로그인 화면에 「허용되지 않은 GitHub 계정입니다」 | 운영자가 이용 계정을 제한해 둔 상태입니다. 운영자에게 GitHub 아이디를 알려 주세요 |
| 커넥터는 Connected인데 SUMA가 동작하지 않음 | 대화창 **+ → Connectors** 에서 SUMA 스위치가 켜져 있는지 확인하세요 |
| 도구 호출 오류(`Invalid content` 등)가 반복됨 | 서버 점검 중일 수 있습니다. 잠시 뒤 다시 시도하고, 계속되면 운영자에게 알려 주세요 |
| 로그인이 자주 풀림 | Customize → Connectors → SUMA에서 **Disconnect → Connect** 로 다시 로그인하세요 |
